How Computational Chemistry Helps Drug Discovery

Six stages, in the order I would follow them.

Molecule representation

I write a molecule as a line of text. A SMILES such as CCO names every atom and bond, so a machine can rebuild the structure.

Property calculation

From that structure I count the atoms and sum their contributions: mass, LogP (affinity for fat over water), and polar surface area.

Drug-likeness prediction

Lipinski's Rule of Five warns me when a molecule is unlikely to be absorbed by mouth. It is a guide, never a verdict.

Molecular comparison

Two candidates on one table reveal which keeps the better balance of properties.

Computational screening

The same calculation can run on thousands of molecules, so that only the most promising reach the bench.

Experimental validation

Every candidate must still be made, measured and tested. Nothing is true in chemistry until the experiment agrees.

Lipinski's Rule of Five: an orally active drug usually has MW ≤ 500 Da, LogP ≤ 5, no more than 5 H-bond donors and no more than 10 acceptors. Computational predictions do not replace laboratory experiments. They only help decide what to test first.

About the Project

This project demonstrates the application of computational chemistry concepts to analyze molecular properties and evaluate basic drug-likeness. It is designed as an educational experimental-learning project.

Objective

Let students enter a molecule and see how structure turns into numbers that guide drug design.

Concepts used

SMILES parsing, molecular graphs, ring counting, fragment-based LogP and TPSA, Lipinski's Rule of Five, force-field-style layout for 2D/3D drawing.

Limitations

LogP and TPSA are simplified estimates and can differ from RDKit by about ±0.5 and a few Å². No stereochemistry, optimised 3D geometry, or ADMET prediction. Only HTML, CSS and JavaScript run in this page.

Future improvements

Connect the RDKit backend below, add Veber and Ghose filters, name lookup via PubChem, and proper 3D conformers.

RDKit backend (optional)

Set API_URL = '/api/analyze' in the page script and run this Flask app. The page then uses RDKit's numbers instead of the built-in estimates.

from flask import Flask, request, jsonify
from rdkit import Chem
from rdkit.Chem import Descriptors, Crippen, rdMolDescriptors as D
app = Flask(__name__)

@app.post("/api/analyze")
def analyze():
    m = Chem.MolFromSmiles(request.json.get("smiles", ""))
    if m is None:
        return jsonify(error="invalid"), 400
    return jsonify(mw=Descriptors.MolWt(m), logp=Crippen.MolLogP(m),
        tpsa=D.CalcTPSA(m), hbd=D.CalcNumHBD(m), hba=D.CalcNumHBA(m),
        rot=D.CalcNumRotatableBonds(m))
