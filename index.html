Workflow

  1. Input a molecule name, CID, or SMILES.
  2. Validate the structure and fetch metadata when available.
  3. Compute properties and drug-likeness filters.
  4. Review the ADMET preview and descriptor heuristic.

This is an educational prototype, not a clinical model.
